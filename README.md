An entry to make.fun's "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty: Learns each launch day's shape from 40+ past launches: a kernel-weighted local fit of hourly log-ratios against the hour-1 audience, with residual quantiles for the spread. Pure Python, deterministic, no network.
